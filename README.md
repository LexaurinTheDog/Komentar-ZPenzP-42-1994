# Komentář k zákonu č. 42/1994 Sb., o penzijním připojištění se státním příspěvkem a o změnách některých zákonů souvisejících s jeho zavedením

Otevřený komentář k zákonu o penzijním připojištění se státním příspěvkem — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; penzijní fond, statut a penzijní plán, smlouva, dávky, příspěvky a státní příspěvek, hospodaření, dohled a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-1994-00042_2024-01-01`.
